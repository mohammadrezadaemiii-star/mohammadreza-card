# وضعیت نسخه وب TankerBot V7

تاریخ: 2026-11-03
شاخه: integration/tanker-ops-v1

## انجام‌شده در این مرحله
- ایجاد صفحه مستقل `tankerbot-v7.html` برای نسخه وب، با رابط فارسی و واکنش‌گرا.
- استفاده از همان Supabase project و publishable key موجود در صفحه ورود کارکنان؛ هیچ service-role key یا توکن پیام‌رسانی در مرورگر قرار نگرفته است.
- ورود کارکنان با Supabase Auth و کنترل نقش فعال از `app_user_roles`.
- جستجوی بانک رانندگان از جدول موجود `waybill_drivers`.
- نمایش سوابق قابل‌دسترسی از جدول‌های `waybills`، `tehran_waybills` و `tabriz_waybills` با رعایت RLS.
- انتخاب فایل Excel/CSV بیتا، استخراج ردیف‌ها، نگاشت ستون‌ها و پیش‌نمایش قبل از هرگونه ثبت.
- لینک صفحه اصلی به پنل V7 اضافه شده است.
- اسکریپت JavaScript صفحه از نظر Syntax بررسی شده است.

## عمداً غیرفعال/در انتظار تکمیل
- ثبت‌نام عمومی راننده: تابع فعلی `register_waybill_driver` نیازمند کاربر مجاز است و برای ثبت‌نام عمومیِ تأییدشده با شماره موبایل مناسب نیست. باید OTP و endpoint امن سمت سرور طراحی شود.
- ثبت نهایی فایل بیتا: تا زمان دریافت نمونه واقعی فایل بیتا و تطبیق ستون‌ها، عملیات نوشتن غیرفعال است تا حواله‌های اشتباه یا تکراری وارد بانک اصلی نشوند.
- مدیریت مدارک رمزنگاری‌شده: نیازمند Storage policy و سرویس سمت سرور برای مدیریت کلیدهاست.
- بارهای قابل جستجو و تطبیق راننده: در اسکیمای فعلی جدول مستقل بارها وجود ندارد؛ باید مدل داده و RLS طراحی شود.
- بله و تلگرام: توکن‌های ارائه‌شده در گفتگو افشاشده محسوب می‌شوند؛ پس از چرخش توکن‌ها باید مقادیر جدید فقط در Supabase Edge Function Secrets ذخیره شوند و webhook/صف اعلان پیاده‌سازی شود.
- زمان‌بندی، retry، جلوگیری از ارسال تکراری، broadcast، VCF و گزارش‌های تکمیلی هنوز عملیاتی نشده‌اند.

## ملاحظات امنیتی کشف‌شده
گزارش Security Advisor فعلی پروژه هشدارهایی درباره SECURITY DEFINERهای قابل فراخوانی از anon/authenticated، دو جدول RLS بدون policy و غیرفعال بودن leaked-password protection نشان می‌دهد. این موارد پیش از فعال‌سازی عمومی باید جداگانه بررسی شوند. هیچ policy یا تابع موجود در این مرحله تغییر داده نشده است.

## انتشار
این تغییرات فقط روی شاخه آزمایشی `integration/tanker-ops-v1` ثبت شده‌اند و روی سایت اصلی منتشر نشده‌اند. برای انتشار عمومی باید ابتدا تست‌های نقش‌ها و RLS، ثبت/خواندن داده، فایل بیتا، امنیت توکن‌ها و پیام‌رسان‌ها کامل شوند و سپس تأیید انتشار گرفته شود.
